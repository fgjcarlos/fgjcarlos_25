# Detalles del Proyecto

Este es un ejemplo de cómo documentar tus proyectos IT/OT. Usar MDX te permite flexibilidad total.

### Desafíos Técnicos

- Integración de protocolos industriales (MQTT/OPC-UA) con WebSockets en tiempo real.
- Despliegue de microservicios en gateways industriales mediante Docker.
- Gestión de datos de sensores en bases de datos de series temporales.

### Stack Técnico Sugerido

- **Edge:** Raspberry Pi / Industrial PC.
- **Backend:** Node.js + Express + InfluxDB.
- **Frontend:** Astro + Tailwind + React (para dashboards reactivos).
