## El problema

Node-RED es la herramienta de referencia para automatización visual e IoT en el edge — flexible, fiable y con una comunidad enorme. Pero operarlo en producción significa SSH a la máquina, editar `settings.js` a mano, gestionar paquetes npm desde terminal, scripts ad-hoc para backups y tail manual de logs. No existe una capa de control oficial.

NRCC cubre ese hueco: un plano de control visual para **una instancia Node-RED 5.x por stack**. Descubre el despliegue, importa `settings.js` sin pérdida, guía cada edición con un diff, valida el resultado, escribe un snapshot de backup, aplica el cambio transaccionalmente y hace rollback si el readiness check falla — sin editar JSON a mano ni entrar al contenedor por shell.

## Qué hace

**Edición transaccional de `settings.js`** — Catálogo tipado de ajustes de alto valor y escape hatches avanzados. Cada cambio sigue el flujo completo: diff con secretos redactados, validación contra las reglas de Node-RED 5, snapshot, apply transaccional y rollback automático si el readiness probe falla.

**Administración de acceso** — Usuarios y roles de NRCC, superficie separada para `adminAuth` de Node-RED y autenticación del Dashboard. Cada superficie de seguridad es independiente.

**Gestión de la instancia** — Ciclo de vida del runtime, logs en vivo, entorno, librería npm, import/export de flows y métricas de sistema.

**Backups y restore** — Snapshots con timestamp en el volumen persistente, montables en volumen separado para sobrevivir a recreaciones del stack.

**Compatibilidad explícita** — Node-RED 5.x con edición completa; 4.x solo detección, inspección read-only y guía de migración; futuros majors en read-only hasta verificar un adaptador dedicado.

## Stack

| Capa           | Tecnología                   |
| -------------- | ---------------------------- |
| Backend        | Go 1.27, Chi router, JWT     |
| Almacenamiento | JSON con file locking        |
| Frontend       | React 19, TypeScript, Vite   |
| Streaming      | Server-Sent Events           |
| Empaquetado    | Frontend embebido en binario |
| API            | OpenAPI 3.1                  |
| Ops            | Docker Compose, instalador   |

Arquitectura **feature-folder** en el frontend, dashboard servido directamente desde el binario Go — un solo artefacto desplegable.

## Instalación

```sh
curl -fsSL https://get.nrcc.dev/install.sh | sh   # stack desde la última release
docker compose up -d --build                      # stack manual
```

Una pila = un NRCC + un Node-RED + un volumen persistente; para más instancias, stacks adicionales en puertos y volúmenes distintos.

## Estado actual

Beta, en fase de hardening: feature-complete para el alcance de Node-RED 5, sin SLA ni auditoría de seguridad externa. Builds solo Linux (en macOS/Windows se usa la imagen Docker), i18n con inglés y español mantenidos, y tag releases publicados desde `main`.
